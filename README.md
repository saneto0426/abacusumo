## 📖 概要 (Overview)

**Sum-O** は、日本の伝統文化である「相撲」と「フラッシュ暗算」を掛け合わせた、新感覚の計算バトルゲームです。  
一人で黙々と解くイメージが強いフラッシュ暗算を、**「計算のスピードで相手と戦うアクション体験」** へと再定義しました。自分の力士が土俵の外に出されないよう、素早く正確に暗算をこなして相手力士を場外へと押し出します。

---

## ✨ 特徴・こだわり (Features)

### ⚡ フラッシュ暗算の新しい楽しみ方
次々と切り替わる数字を瞬時に足し合わせるフラッシュ暗算を、スリリングな1対1の相撲バトルに昇華しました。計算をトレーニングとしてではなく、直感的なゲームとして楽しめます。

### 🔥 計算の素早さで競う白熱のバトル
回答の「正確さ」と「スピード」が力士のパワーに直結します。相手より素早く計算して正解するほど力強く前進し、逆に遅れたり間違えたりすると土俵際へと追い詰められます。自分の力士が場外に出ないよう踏みとどまりながら、相手を一気に押し出す駆け引きが魅力です。

### 🎨 すべて手描きの「浮世絵テイスト」ビジュアル
ゲーム内の力士や背景、UIパーツなどのイラストは**すべてオリジナルの手描き**で制作しています。江戸時代の浮世絵から着想を得た力強いタッチと和の色彩で、暗算バトルの緊張感と日本らしい世界観を表現しました。

## 🎮 遊び方 (How to Play)

1. **立ち合い（ゲーム開始）**: 行司の合図とともに、画面に数字がフラッシュ表示されます。
2. **暗算・入力**: 表示された数字の合計を素早く頭の中で計算し、答えを入力します。
3. **押し合い**: 正解するスピードに応じて、あなたの力士が相手を押し込みます。
4. **決まり手（勝敗）**: 自分の力士が土俵から出ないように守りつつ、相手力士を土俵の外（場外）へ押し出せば勝利です！
